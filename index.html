狩歌抢词桌

一台 iPad 放在桌中央，四角抢身份，中间点词卡。适合 2-4 人线下边听歌边抢。

游玩说明

  • 开始铺牌后，在“音乐”里搜索网易云歌曲；需要完整播放时先扫码登录网易云。
  • 歌曲载入后会读取歌词，并为本首歌动态生成词卡；
  • 音乐开始播放后，时间会按歌曲剩余时长倒计时，音乐栏会缩成当前歌词提示。
  • 多人模式把词卡拖到自己的颜色区域；单人模式直接点词卡。
  • 系统会按抢答时的当前歌词行和上一行自动判定，命中加分，未命中扣分。

更新说明

  • 新增网易云扫码登录、搜歌、播放地址和歌词加载。
  • 新增 AI 歌词词库，未配置 API key 时自动回退本地分词。
  • 取消固定 1 分钟轮次，改为跟随歌曲时长。
  • 正确/错误改为自动判定，减少人工裁判操作。
